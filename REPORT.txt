2. Comandos Git:
- git clone <URL>: Clonar repositorio
- git checkout -b <rama>: Crear una nueva rama
- git add <archivos>: Añadir cambios al área de preparación
- git commit -m "mensaje": Confirmar cambios
- git push origin <rama>: Subir cambios al repositorio
- git merge <rama>: Fusionar ramas
- git push origin --delete <rama>: Eliminar rama
